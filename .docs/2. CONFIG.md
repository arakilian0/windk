# Windk Config Manager

The `config_manager.bat` utility provides a stateless, high-performance interface for on-demand `GET` lookups and atomic `SET` updates on `.cfg` / `.ini` configuration files. By evaluating keys dynamically at execution time, it eliminates Windows Batch's 32 KB environment memory limit while keeping your CLI runner's process footprint near zero.

---

## Technical Features

* **Just-In-Time (JIT) Key Resolution**: Queries configuration files line-by-line on demand, returning values directly to isolated caller variables rather than bulk-loading entire files into environment memory.
* **Special Character & Equals Sign Protection**: Preserves poison characters (`!`, `^`, `&`) and inline equal signs (`=`) using strict token splitting (`tokens=1* delims==`) and `DisableDelayedExpansion` scoping.
* **Relative Path Normalization**: Values beginning with `.` or `..` are automatically expanded into absolute file system paths relative to the directory housing the `.cfg` file.
* **Recursive `@:` Alias Pointer Resolution**: On-the-fly resolution follows alias pointer chains up to 3 hops deep directly inside `GET` lookups.
* **Dangling Pointer Defense**: Automatically clears and unsets broken `@:` references when target alias keys do not exist in the configuration file.
* **Atomic `SET` Operations**: Preserves layout, comments, and spacing while modifying keys. Write updates are output to temporary files before executing an atomic swap (`move /y`) to protect against configuration corruption.

## Pipeline Architecture

```text
[ On-Demand Call: config_manager.bat GET/SET ]
                       │
                       ├────────────────────────────────────────┐
                       ▼                                        ▼
┌───────────────────────────────────────────┐ ┌───────────────────────────────────────────┐
│ GET OPERATION                             │ │ SET OPERATION                             │
│ - Scan .cfg line-by-line for target key   │ │ - Stream lines to temp file (.tmp)        │
│ - Skip non-matching section headers       │ │ - Preserve comments (; or #) & empty lines│
│ - Evaluate @: pointers (up to 3 hops)     │ │ - Overwrite existing key or create section│
│ - Expand relative paths (.\ or ..\)       │ │ - Perform atomic file swap (move /y)      │
│ - Export single variable & purge context  │ └───────────────────────────────────────────┘
└─────────────────────┬─────────────────────┘
                      │
                      ▼
┌───────────────────────────────────────────┐
│ Output Handshake                          │
│ - Populate RET_VAR in caller scope        │
│ - Retain zero residual parser state       │
└───────────────────────────────────────────┘
