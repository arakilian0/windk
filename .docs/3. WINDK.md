# Windk Main Runner

The `tool/windk/cli.bat` script acts as the primary entry point and stateless dispatcher for the Windk CLI. It parses incoming arguments, categorizes flags and positional parameters, queries `lib/config_manager.bat` on demand, and forwards execution state down to independent subcommand executables without polluting global process memory.

## Technical Features

* **Stateless, On-Demand Resolution**: Queries `lib/config_manager.bat` JIT (Just-In-Time) upon encountering flags (`-`, `/`) or subcommands, evaluating entries dynamically to bypass Windows' 32 KB environment limit without preloading bulk tables.

* **Passthrough Flag Forwarding**: Distinguishes immediate flags (e.g., `--help`, `--version`) from operational flags (e.g., `--verbose`, `--force`), forwarding operational flags directly to target subcommands.

* **Delegated Execution Router**: Acts strictly as an orchestration gateway, passing argument parsing and subcommand logic down to individual child scripts.

* **Automated Error Fallbacks**: Automatically resolves and executes the default help module when receiving unrecognized subcommands or empty parameter calls.

                            │
                            ▼

│ STEP 2: Iterative Argument Tokenization Loop           │

│ - Evaluate token prefix (-, /, or positional token)    │
└─────────────┬────────────────────────────┬─────────────┘
              │                            │
  (Flag Detected)                (Positional Detected)
              │                            │
              ▼                            ▼

              │                            │
              └─────────────┬──────────────┘
                            │
                            ▼

│ - Call child script and exit with child exit code      │
└────────────────────────────────────────────────────────┘
